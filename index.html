How to Install as an App

  • iPhone/iPad (Safari): Tap the Share icon (square with arrow pointing up) at the bottom of the screen, scroll down, and tap Add to Home Screen.
  • Android (Chrome): Tap the 3-dot menu icon in the top right, then tap Add to Home screen or Install app.
  • Desktop (Chrome/Edge): Click the install icon (monitor with a down arrow) on the far right side of the URL address bar, or go to the browser Menu > Save and share > Install page as app.
